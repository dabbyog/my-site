``` ## How To Use It 1. Create a new GitHub repository. 2. Upload this file as `index.html`. 3. Upload your profile photo as `profile.jpg`. 4. Turn on GitHub Pages: * Repo Settings → Pages * Source → Deploy from branch * Branch → main 5. Connect your Porkbun domain: * In GitHub Pages settings, add your custom domain. * In Porkbun, point the domain to GitHub Pages DNS records. Then your Beacons link can be replaced with your own custom domain entirely for free.
